# Снегопад

Уютный зимний сайт-хранилище воспоминаний для нас и наших друзей: фотографии и видео, комментарии, альбомы, стена пожеланий, отсчёт до Нового года и спокойная фоновая музыка под падающим снегом.

## Технологии

- **Next.js** (App Router, Turbopack) + React 19 + TypeScript
- **PostgreSQL** + **Drizzle ORM**
- **Tailwind CSS 4**, **Framer Motion**, **Lucide** иконки
- PWA-манифест — сайт устанавливается как отдельное приложение

## Возможности

- Загрузка фото и видео (drag-and-drop, до 30 файлов за раз) с автором, подписью и привязкой к альбому
- Комментарии к каждой фотографии
- Альбомы с обложками и счётчиками
- Общая галерея с фильтрами и полноэкранным лайтбоксом (скачивание, удаление, стрелки, клавиатура)
- Стена новогодних пожеланий
- Отсчёт до Нового года в реальном времени
- Фоновая музыка «Silent Night» (Kevin MacLeod, CC BY 3.0)
- Потоковая отдача медиа с поддержкой HTTP Range (перемотка видео)

## Запуск локально

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Создайте файл `.env` (см. `.env.example`) и укажите `DATABASE_URL` — строку подключения к PostgreSQL.
3. Примените схему к базе данных:
   ```bash
   npx drizzle-kit push --config=drizzle.config.json
   ```
   (в `drizzle.config.json` тоже укажите свой адрес базы)
4. Запустите:
   ```bash
   npm run dev      # разработка
   npm run build && npm start   # продакшен
   ```
5. Откройте http://localhost:3000

## Куда что сохраняется

- Загруженные файлы — в папку `uploads/` на сервере, раздаются через `/api/files/...`
- Метаданные (альбомы, воспоминания, комментарии, пожелания) — в PostgreSQL
- Для облачного деплоя (Vercel и т.п.) файловое хранилище стоит перенести в S3/Cloudinary/Vercel Blob
